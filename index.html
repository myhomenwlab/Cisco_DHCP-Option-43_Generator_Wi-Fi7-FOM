Cisco DHCP Option 43 Generator (Wi-Fi 7 APs - FOM)

Cisco Wi-Fi 7 AP (CW917xシリーズ)向けのFast Offline Migration (FOM) 用DHCP Option 43のHEX値を生成します。

WLC #1
WLC #2
WLC #3
Mode
HEX: 02
DHCP Option 43 (HEX)
生成された値をそのままDHCP Option 43の設定値に使用できます。 

    
  


  






  
説明

  
    
    
  • Cisco Wi-Fi 7 AP (CW917xシリーズ)がFast Offline Migration (FOM)を利用してCatalyst Mode (WLC Mode)またはMeraki Modeへ移行するためのDHCP Option 43を生成するツールです。
    • 
    
  • 入力されたWLCのIPv4アドレスを16進数 (HEX)形式へ変換し、F3 + Length + WLC IP + Modeの形式で出力します。
    • 
    
  • ModeはCatalyst Mode (WLC Mode)が 02、Meraki Modeが 01 です。
    • 
    
  • Meraki ModeではWLCのIPv4アドレスを入力せずに f30101 を生成できます。Catalyst Mode (WLC Mode)ではWLCのIPv4アドレスが1つ以上必要です。
    • 
    
  • 本ツールはクライアント側のJavaScriptによって動作しており、外部のサーバーには送信を行いません。
    • 
    
  • DHCP Option 43のFOMはWi-Fi 7 APのDay 0におけるCatalyst / Meraki Modeの自動変換に使用できます。
    • 
  






  
DHCP Option 43のフォーマット



<Type><Length><WLC #1><WLC #2><WLC #3><Mode>





  
項目値の例説明

  
Typef3Fast Offline Migration用。DHCP Option 43のサブオプションコード243 (0xf3)で固定

  
Length0d4 Bytes × WLCの数 + 1 Byte (1台: 0x05, 2台: 0x09, 3台: 0x0d)

  
WLC #10a00ff65WLC #1のIPv4アドレスのHEX形式 (例示IPアドレス: 10.0.255.101)

  
WLC #2ac102066WLC #2のIPv4アドレスのHEX形式 (例示IPアドレス: 172.16.32.102)

  
WLC #3c0a88067WLC #3のIPv4アドレスのHEX形式 (例示IPアドレス: 192.168.128.103)

  
Mode0201 = Meraki Mode、02 = Catalyst Mode (WLC Mode)
